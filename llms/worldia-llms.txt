# Worldia

> Worldia is a Paris-based B2B2C travel technology company (founded 2012, headquartered in
> Montreuil, France) whose platform lets travel distributors, retailers and agents build,
> price and book personalized tailor-made trips across 80+ destinations. Partners are
> onboarded as branded "channels" — 388 are live — each with its own storefront, currency,
> locale and legal document set.

This file was generated by API Evangelist from artifacts in this repository. It is not
published by Worldia. Worldia serves no llms.txt of its own on any host.

## Important caveats for an agent

- **There is no OpenAPI, GraphQL SDL, AsyncAPI or Postman collection.** Worldia publishes no
  machine-readable API contract and no developer documentation. Everything below was
  established by probing the live API on 2026-09-04.
- **There is no self-service access.** No signup, no API keys page, no sandbox, no pricing.
  Access is negotiated commercially through a demo request.
- **The API advertises documentation it does not serve.** Every response carries a Hydra
  `apiDocumentation` Link header pointing at https://api.worldia.com/docs.jsonld, and that
  URL returns HTTP 404 under every content type. Do not treat the header as a live pointer.
- **Do not infer write semantics.** The JSON-LD model describes trips, checkouts, payments
  and archival, but no write operation, cancellation path or refund window is documented
  anywhere. Never assume a booking made through this API can be reversed, or within what
  period. That is a question for Worldia, not for inference.

## API

- [Worldia API](https://api.worldia.com): Production REST API built on API Platform
  (Symfony). Content-negotiates `application/vnd.worldia+json` (default,
  `{meta,data}` envelope), `application/ld+json` (Hydra collections), and
  `application/problem+json` (errors). `https://api.prod.worldia.com` is a 301 alias.
- Authentication: bearer JWT (`Authorization: Bearer <token>`; a missing token returns
  `{"code":401,"message":"JWT Token not found"}`). No OAuth2 and no OpenID Connect — both
  well-known documents 404 on every host. No token endpoint is publicly routed.
- Tenancy: channel-scoped collections require an `X-Channel` header naming a registered
  channel code. This is a tenant selector, not a credential; valid codes are readable
  anonymously at `GET /channels`.
- Pagination: `page` (1-based) and `itemsPerPage`, default page size 30. Hydra responses
  carry `hydra:totalItems` and a `hydra:view` PartialCollectionView.
- Filtering: advertised per collection as a `hydra:search` IriTemplate. There is no single
  document listing them; they are discovered by calling each collection.

## Readable without credentials

- `GET /channels` — 388 distribution channels, each with branding, hostname, currency, locale.
- `GET /channels/{code}` — one channel, e.g. `/channels/B2B-LTUR-DE`.
- `GET /locations` — geographic hierarchy, typed `https://schema.org/Place`. Advertises a
  hydra:search template with `full_text_search_name`, `fuzzy_name`, `leaf`, `level`,
  `promoted`, `parent`, `root` and `addressComponents.type`.
- `GET /themes` — 24 trip themes (requires `X-Channel`).
- `GET /accommodations` — 16,943 properties (requires `X-Channel`).
- `GET /inspirations` — 971 itinerary templates (requires `X-Channel`). Note the members
  identify themselves as `/templates/{id}`.
- `GET /airports` — air gateway reference data with IATA and ICAO codes (requires `X-Channel`).
- `GET /contexts/{Type}` — JSON-LD context documents.

## Requires authentication

- `GET /customers` — 401, `WWW-Authenticate: Bearer`.
- `GET /templates` — 403, "Unable to access as unauthorized user".

## Machine-readable artifacts Worldia does publish

- [JSON-LD contexts](json-ld/worldia-json-ld.yml): 16 context documents, 723 declared terms,
  fetched verbatim from `/contexts/{Type}` — Channel, Location, Place, Template, Theme, Trip,
  Customer, Accommodation, Airport, Payment, Agent, Transfer, Car, Train, Document, Route.
  These are the only machine-readable description of the Worldia model in existence.
